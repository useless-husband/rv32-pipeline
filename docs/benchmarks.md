Configurations:

- `single`: core A, single cycle, ideal memory
- `pipe`: core B default: I$ 4 KiB DM, D$ 4 KiB 2-way WB, BTB 128 + BHT 256 + RAS 8, memory latency 10
- `pipe-nobp`: core B, predictor off (always not taken)
- `pipe-noras`: core B, no return-address stack
- `pipe-ic8k`: core B, 8 KiB I-cache
- `pipe-lat1`: core B, memory latency 1 cycle
- `pipe-lat30`: core B, memory latency 30 cycles

Cycle ratio, single-cycle / pipelined (default):

- coremark: 10,362,422 / 12,201,403 = 0.849 (the pipelined core needs 1.18x the cycles)
- dhrystone: 259,531 / 362,939 = 0.715 (the pipelined core needs 1.40x the cycles)

Estimated run time with the logic-only path delays from `make sta` (core A 56.2 ns, core B 7.8 ns; no routing, not timing sign-off, see synth/timing.md):

- coremark: 581.92 ms vs 95.77 ms, pipelined core about 6.1x faster
- dhrystone: 14.57 ms vs 2.85 ms, pipelined core about 5.1x faster
