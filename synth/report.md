# Synthesis report (Yosys, Spartan-7 XC7S50)

Generated by `make synth` (`synth_xilinx -family xc7`, scripts in `synth/`). Each core is synthesised on its own with its memory interface as the top-level ports (core B twice: as RV32IM, and with the FPU parameter set, RV32IMFD); the commit port and viewer probes are left unconnected, so logic that only feeds verification is removed. Core A's instruction and data memories are outside the core (they are combinational reads, which a real single-cycle design would need as asynchronous RAM); core B's caches are inside and map to block RAM.

The core with the FPU uses 49.2% of the XC7S50's LUTs and 16 of its 120 DSP blocks (the 53 x 53-bit significand multiplier takes 12).  The difference is more than the FPU block itself: the f register file, three 64-bit forwarding muxes and the F/D pipeline registers are in the core.

## What these numbers are not

Yosys maps to 7-series cells but does not place, route or time them, and no open-source flow gives timing sign-off for this part. `make sta` writes a logic-only delay estimate to [timing.md](timing.md), useful only for comparing the cores. None of them has been run on a real board.
